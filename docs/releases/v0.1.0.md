# Easy Agent v0.1.0 Release Notes

> 发布日期：2026-11-24 · 里程碑：Phase 1 MVP（Phase 1.1～1.6）

Easy Agent `v0.1.0` 是首个可运行的 MVP 里程碑。基于「四个运行职责层（Application / Agent / Execution / Runtime）+ 横向 Harness + Composition / Bootstrap」架构，本版本完成了从模型访问、本地工具执行、默认 Agent Loop、内存 Execution Engine、多轮 Session 管理到统一应用服务与本地 CLI 的端到端闭环。

## 核心能力

- **工程基线与统一日志（Phase 0 / Logging）**
  - Node.js 26.x LTS + TypeScript 6.0.3（`strict`、ESM），提供 `typecheck`、`lint`、`format:check`、`build`、`test` 全套离线工程脚本。
  - 供应商无关的 `Logger` 门面（默认 Pino 输出结构化 JSON 到 stderr），支持四级过滤、`LOG_LEVEL`、子 logger、Error 结构化序列化和敏感字段/敏感值脱敏。
- **Model System（Phase 1.1）**
  - 定义 `ModelClient` 公共契约并提供 `OpenAICompatibleModelClient`（Chat Completions），支持 `generate()` / `stream()`、流式增量与 Tool Calling 组装、Usage 映射、统一 `ModelError`、单次请求取消/超时、实例级自然并发与安全生命周期日志。
  - 兼容流式及非流式响应中的空白工具标识与 `null` 占位字段，同时对冲突标识和缺失必需字段保持严格校验。
- **Tool Runtime（Phase 1.2）**
  - 提供 `DefaultToolRegistry`、`DefaultToolExecutor` 与 Model 数据桥接（`toModelToolDefinition`、`toToolResultMessage`）。
  - 基于 Ajv draft-07 的严格 JSON Schema 输入校验（不补默认值、不隐式类型转换、不静默删字段）、注册快照隔离、并发执行、业务失败返回 `ToolResult`、取消/超时抛出 `ToolExecutionError`。
- **Agent Loop（Phase 1.3）**
  - 定义策略无关的 `AgentLoop` 公共契约，自定义实现允许不依赖模型或工具。
  - 提供 `DefaultAgentLoop`：仅使用 `ModelClient.stream()`、按模型返回顺序串行执行工具、维护完整已确认历史，并在当前尝试尚未公开事件且错误明确可重试时执行受控模型重试（默认 `maxModelRetries: 2`）。
- **Execution Engine（Phase 1.4）**
  - 定义 `ExecutionEngine` 公共契约并提供 `DefaultExecutionEngine`，可驱动任意符合契约的 `AgentLoop`。
  - 支持惰性单次消费事件流、`RUNNING` / `COMPLETED` / `FAILED` / `CANCELLED` 生命周期、协议校验、协作式取消与有界终态内存快照（默认保留 1000 条）。
- **Agent Management（Phase 1.5）**
  - 定义 `AgentManager` / `SessionAgent` / `SessionExecution` 契约并提供 `DefaultAgentManager`。
  - 支持进程内多轮 Session、`submit()` 同步入队、同 Session FIFO、跨 Session 并发、执行启动时读取最新上下文、仅 `COMPLETED` 且存在 `updatedContext` 时提交历史、排队/运行取消，以及与执行解耦的有界单消费者 `events` 观察流和独立 `result`。
- **Application Service、Composition 与本地 CLI（Phase 1.6）**
  - 提供面向本地 CLI 与未来 HTTP 复用的统一 `AgentApplicationService` 及稳定应用错误分类。
  - 提供 `resolveConfig` / `loadConfig` / `bootstrap`：统一配置优先级为 **CLI 显式选项 > 环境变量 > 显式 JSON 文件 > 默认值**，支持可替换组件注入、启动失败回滚、幂等 `dispose()` 以及内置无外部副作用的纯计算示例工具 `add({ a, b })`。
  - 提供本地交互入口 `easy-agent chat`，支持流式 `output_delta` 正文输出、`--no-stream`、`/new` 新建切换 Session、`/exit` 顺序清理退出以及 Ctrl+C 显式取消并等待协作收尾。

## 快速开始

```bash
npm ci
OPENAI_API_KEY='your-api-key' \
EASY_AGENT_BASE_URL='https://your-provider/v1' \
npm run chat -- --model your-model-id
```

构建后也可直接运行原生 ESM 入口（无需 TypeScript 运行支持）：

```bash
npm run build
node dist/application/cli/bin.js --version
node dist/application/cli/bin.js chat --model your-model-id
```

## 已知边界与尚未实现的能力

`v0.1.0` 聚焦最小可用的进程内本地 Agent MVP，以下能力留待 Phase 2 及后续阶段规划与实施：

- **传输与产品入口**：HTTP Server、REST / SSE 接口、远程 CLI、Web UI、正式 npm SDK 发布（当前为 `private: true` 私有包，且未将 `npm link` 作为安装验收项）。
- **持久化与恢复**：Session Event Log JSONL 读写、Transaction Journal、Write Coordinator、持久化投影、事件重放、崩溃恢复（当前 Session 与快照仅驻留进程内存，退出后不保留）。
- **事件与高级调度**：Runtime Event Bus、多订阅者广播、持久化 Inbox、Steer / Follow-up、完整 Turn / Step / Attempt 状态机。
- **扩展与治理**：MCP、Skill、Memory、Token 预算与上下文压缩、Workspace、Sandbox、Approval / HITL、多 Agent、工具并行执行。
- **可观测性扩展**：日志轮转、远端日志采集与分布式 Tracing。
